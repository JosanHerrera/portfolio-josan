## Sobre este proyecto

Portfolio personal desarrollado íntegramente mediante **Claude Code** (Anthropic) utilizando prompts de ingeniería precisos y estructurados, sin escribir código manualmente.

Todo el diseño, la arquitectura, los efectos visuales y la lógica interactiva fueron generados a través de instrucciones prompt diseñadas para obtener resultados production-ready a la primera iteración.

---

## Stack técnico

- **HTML5 + CSS3 + JavaScript vanilla** — sin frameworks, sin build step
- **Tailwind CSS** via CDN
- **Canvas API** — juego arcade integrado
- **Google Fonts** — Anton + Space Mono + Syne
- **Vercel** — despliegue y hosting

## Metodología

Este proyecto demuestra que con **Prompt Engineering** bien aplicado es posible construir productos web completos y con calidad visual alta sin necesidad de escribir código línea a línea.

El flujo de trabajo seguido:

1. Diseño del sistema visual (colores, tipografía, efectos) en prompt
2. Generación sección por sección con Claude Code
3. Iteración quirúrgica — solo se modificaba lo que no funcionaba
4. Validación previa de componentes complejos (juego arcade) antes de integrar
